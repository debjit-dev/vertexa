Architecture highlights

Static-first, deploy-friendly

The site ships as plain HTML/CSS/JS files with no application server to patch or scale. New pages are added the same way as the first ten. A simple CI step can minify assets and optimize images automatically on every push, so deploys stay fast and repeatable as the site grows.
